# 숨 결투장 v2.17.1

설정집 3판(`WORLD.md`)의 규칙으로 도는 마법 결투 시뮬레이터. 규격은 `SPEC.md`.

v2.0부터 기본 규칙은 하이 리스크 + 소금 원 + 파도, 강자끼리가 한 방 싸움이 되지 않게 몸 받침(받는 마법 피해 ÷ C^2.3)·회피를, 대마법사가 걷지 않게 비행(높이 z, 속도 판단, 대마법사가 끼면 200 × 150 m)을 켠다. 1.x의 기본 동작은 `rules: A.V1_RULES`(SPEC 24장, `reports/v2.0.0.md`). v2.1은 벽·빛·군대·사기와 "장악권은 만드는 것을 빼앗지 가는 것은 못 막는다"(도달 반경), 굳은 살을 더했다(SPEC 25장, `reports/v2.1.0.md`). v2.2는 대마법사끼리의 고수 싸움 두뇌(리듬·장악권 밀기·효과 학습·지형 설계)를 더했다(SPEC 26장). v2.3은 날기 끊기(급정지·떨어지기·공기 쿠션)와 진지(함정 한도·연쇄·하늘 덮개·짓기)를 스위치로 더했다(SPEC 27장, 기본 꺼짐). v2.4는 두 겹의 두뇌(매 걸음의 반사 겹), 끊는 움직임(가속 한계·발놀림), 청사진 짓기(`data/blueprints.json`), 매 걸음 녹화와 이어 그리기를 더했다(SPEC 28장, 기본 꺼짐). v2.5는 두뇌의 세 번째 겹(1~2 s마다 작전: 진지·소모·압박·몰이·사냥·끝내기)과 각도 판단(상대 둘레 자리를 재며 원을 그리기), 전설의 강요하는 수를 더했다(SPEC 29장, 기본 꺼짐). v2.6은 대가부터 스스로 죽지 않게(머리 넘침·고르지 않은 파도·굳을 위험에 낮게 날기·소금 원의 단단한 벽) 하고 막힌 직사를 끊고 빈틈을 찌른다(SPEC 30장). 걸음마다 보는 지표는 `metrics/watch.js`, 진단은 `node experiments/diag.js`. v2.7은 상위·대마법사의 머리·당 회복을 선명도로 늘리고(버티기) 마법의 부딪힘에도 비율 감쇠를 주어(상위의 돌 비가 대마법사를 한 방에 죽이지 않는다) 대마법사끼리의 판이 쓰러뜨림으로 끝나게 했다(SPEC 31장). v2.8은 두 번째 칸에 다 지은 공격을 붙잡았다가 틈에 풀게 하고(붙잡아 둔 설계), 맞을 가망으로 쏠지를 정하게 했다(SPEC 32장). v2.9는 틈에 몰아치고, 기다리는 동안 빈 칸으로 벽·함정을 짓고, 세운 벽에 머물게 했다. 버전마다의 성적표는 `node cli.js report` → `reports/scorecard.md`(SPEC 33장). v2.10은 명중 가망을 전설의 기술로 올려 단계 사다리를 바로 세우고, 상대의 시야 공격에만 벽을 세우고, 상위에게 협공을 주었다(SPEC 34장). v2.11은 당 회복을 3 g/s로 올리고 판마다 세 번 쓰는 숨(당·머리·기력을 채운다)을 더했다(SPEC 35장). v2.12는 두뇌가 먼저 공격 방식(견제·확정타·덮기·큰 한 방·던지기)을 고르게 했다(SPEC 36장). v2.13은 결판 뒤 멍하니 서지 않게(교전 유지)·덫을 길 따라 놓게 하고, 샌드박스에 따라가는 카메라와 사건 줄을 더했다(SPEC 37장).

## 바로 쓰기 (Node 18 이상, 설치할 것 없음)

```
node test/test.js                          # 회귀 시험
node cli.js bench                          # 속도
node cli.js duel 평범 평범 20              # 같은 등급 20판
node cli.js duel 상위 상위 10 합법\ 최강 기본기
node cli.js ring 대마법사 평범 50 기본기 5  # 둘러싸기
node cli.js ring 대마법사 병사 40 머스킷 5
node cli.js league 평범 6                  # 원소 기본책 총당
node cli.js replay 상위 상위 replay.json   # 녹화 → viewer.html에 끌어다 놓기
node cli.js scene sandbox/scenes/duel.json  # 장면 한 판 (샌드박스와 같은 결과)
node cli.js suite                          # 표준 시험 묶음: 기준과 비교해 바뀐 줄만 (--save로 기준 저장, 코어 수만큼 병렬)
node cli.js report                         # 성적표: 버전마다 같은 잣대로 재서 reports/scorecard.md에 쌓는다 (v2.9)
```

## 샌드박스 v0.2

`sandbox/index.html`을 브라우저로 연다(서버 필요 없음). 사람·바위·화약통·벽을 놓고, 등급·덱·두뇌 성향·규칙을 바꾸고, 여러 편을 싸움 붙인다. 장면은 JSON으로 내보내고 다시 불러온다. 같은 장면·씨앗이면 명령줄과 결과가 같다. 자세한 것은 SPEC 19장.

v2.15부터 판단 그림에 수읽기(체크·메이트·상대의 방어 자원·피할 곳)가 보인다(장면 `v2-chess-legend`). v0.2(엔진 v2.14)는 중계처럼 본다: 0.1배·0.25배 느리게, 큰 피해·덫 발동·쓰러짐·속임수·미끼 덮기 **직전에** 저절로 느려지기(같은 판을 앞서 돌려 미리 안다), 되감기 막대, 판단 그림(몰이 화살표, 갈 곳 점과 덮는 마법, 노리는 자리와 실제 자리, 속임수, 걸어둔 마법), 따라가는 카메라. 예시 장면 `v2-pace-compare`는 대마법사 전설 대 전설과 평범 대 평범을 같은 시간만큼 나란히 돌린다.

`src/`·`metrics/`·`data/`·`sandbox/scenes/*.json`을 고쳤으면 `node cli.js pack`으로 `sandbox/arena.js`(엔진·데이터·장면을 한 장에 싼 것)를 다시 싼다(안 하면 시험이 알려 준다). 빌드 도구는 없다.

## 구조 (SPEC 22장)

| 자리 | 하는 일 |
|---|---|
| `src/core.js` | 규칙의 바탕: 세계, 물리, 마법 방출, 장악권, 피로, 녹화. 켜진 규칙의 훅을 부른다 |
| `src/rules/` | 규칙 하나에 한 파일: 장비, 지대, 소금 원, 파도, 몸 묶기, 하이 리스크, 도발, 서클, 화약통, 대응(풀기·대비·순간 반응), 은실 옷 |
| `src/brain/` | 기본 두뇌 (바꿔 끼울 수 있음): 읽기·입장·움직임·고르기, `techniques/`(기술 하나에 한 파일), `skills.js`(판단 수준) |
| `src/index.js` | 등급·덱·싸움 배치·장면·학습 API |
| `src/registry.js` | 등록: 마법·덱·등급·두뇌·규칙 |
| `src/math.js`, `src/data.js` | 결정론 수학, 데이터 읽기 |
| `data/` | 마법(원소마다 한 파일), 원소별 기본책, 덱, 등급, 판단 수준, 장비 (JSON) |
| `metrics/` | 행동 지표 |
| `experiments/` | 병렬 실행기(`par.js`, 결과는 한 줄로 돌린 것과 같다), 결과 지문(`hash.js`), 대결 재기(`versus.js`) |
| `cli.js` | 명령줄 |
| `test/test.js` | 규격 시험 |
| `test/suite.js`, `suite-baseline.json` | 표준 시험 묶음과 기준 |
| `reports/`, `REPORT.md` | 버전마다 측정 보고, 요약과 목차. `reports/scorecard.md`는 버전마다의 성적표 |
| `viewer.html` | 녹화 보기 |
| `sandbox/` | 샌드박스 화면, 예시 장면, `arena.js`(묶음) |

## 새 마법·규칙 넣기

마법: `data/spells/원소.json`에 틀(`t`)과 필드를 맞춰 한 항목 추가 → `node cli.js pack` → 덱에 넣고 `node cli.js duel`로 확인. 파일을 고치지 않고 붙이려면 `Arena.register.spell(...)`(SPEC 19장).

규칙: `src/rules/`에 규칙 모듈 한 파일(스위치, 엔진 훅, 두뇌 훅)을 더한다. 정해진 훅에만 끼어들고, 끄면 예전과 같아야 한다(SPEC 22장).
