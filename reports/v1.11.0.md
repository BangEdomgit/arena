# 시뮬레이션 보고 v1.11.0 — 몸 묶기

[← 보고 목차](../REPORT.md). 절 번호는 예전 한 장짜리 REPORT의 번호 그대로다(다른 문서가 'REPORT 13절'처럼 가리킨다).

## 20. v1.11.0: 몸 묶기 — 시간 판정은 얼마나 줄었나

소금 밑창은 발밑(안 보이는 구름)만 막는다. 몸을 묶는 마법 다섯(균사 그물·얼음 족쇄·근육 경직·석회 굳히기·가두는 기둥)과 눈멂의 읽기 막기를 `rules.bodyBind`로 넣고, 대가·전설의 짝 계획이 이것들로도 큰 수의 틈을 열게 했다(SPEC 7·9·13장). 꺼 두면 표준 묶음 80줄이 1.10.0과 같다(아래 버그 수정 13줄을 빼면 모두 같음, 그 13줄도 모두 운 범위 |z| < 1.1).

### 판단 줄 (덱 합법 최강, 400판, ±5%p)

| 등급 | 쌍 | risk · 시간 판정 · 큰 수 맞음 | risk + 몸 묶기 | risk + 소금 원 | risk + 몸 묶기 + 소금 원 |
|---|---|---|---|---|---|
| 평범 | 중급/초보 | 89.0% · 0 · 42% | 89.0% · 0 · 42% | 89.3% · 0 | 89.3% · 0 |
| 평범 | 상급/중급 | 94.6% · 19 · 19% | 94.4% · 22 · 19% | 94.3% · 3 | 94.5% · 3 |
| 평범 | 대가/상급 | 82.4% · **137** · 28% | 80.6% · **133** · 38% | 83.1% · **12** | 82.0% · **17** |
| 평범 | 전설/대가 | 58.1% · **222** · 29% | 59.9% · **211** · 50% | 50.5% · **27** | 54.8% · **29** |
| 중간 | 중급/초보 | 86.0% · 0 · 58% | 86.0% · 0 · 58% | 86.0% · 0 | 86.0% · 0 |
| 중간 | 상급/중급 | 81.0% · 0 · 25% | 81.0% · 0 · 25% | 81.0% · 0 | 81.0% · 0 |
| 중간 | 대가/상급 | 46.6% · 0 · 35% | 49.8% · 0 · 40% | 46.6% · 0 | 49.8% · 0 |
| 중간 | 전설/대가 | 50.2% · 0 · 0% | 48.4% · 0 · 13% | 50.2% · 0 | 48.4% · 0 |

(시간 판정은 400판 중 몇 판. 중간은 판이 9 s 안팎이라 시간 판정이 없다.)

- **몸 묶기는 시간 판정을 거의 줄이지 못했다**: 평범 대가/상급 137 → 133(−3%), 전설/대가 222 → 211(−5%). 오차 안이다. 소금 원은 137 → 12, 222 → 27로 여전히 이것을 줄이는 수단이다. 둘을 함께 켜도 소금 원만 켠 것과 같다
- **큰 수의 적중은 올랐다**: 평범 대가/상급 28 → 38%, 전설/대가 29 → 50%, 중간 전설/대가 0 → 13%. 몸 묶기로 붙잡은 과녁에 큰 수를 꽂은 횟수는 400판에 대가 73번, 전설 11번이다. 그러나 큰 수가 드물어(한 판에 1번이 안 된다) 판 길이를 바꾸지 못한다
- 중급·상급은 새 마법을 거의 쓰지 않는다(약한 공격으로 치지 않으므로). 그 줄은 risk와 같다
- 승률은 모두 오차 안이다(평범 대가/상급 82.4 → 80.6%, 중간 대가/상급 46.6 → 49.8%)

### 덱 기술 (산 안개로 눈멂이 있다, 300판, ±6%p)

| 등급 | 쌍 | risk · 시간 판정 · 큰 수 맞음 | risk + 몸 묶기 |
|---|---|---|---|
| 평범 | 상급/중급 | 95.7% · 1 · 20% | 95.2% · 3 · 20% |
| 평범 | 대가/상급 | 51.5% · **49** · 29% | 54.7% · **33** · 34% |
| 평범 | 전설/대가 | 37.3% · **101** · 31% | 38.7% · **108** · 58% |
| 중간 | 상급/중급 | 85.0% · 0 · 26% | 85.0% · 0 · 26% |
| 중간 | 대가/상급 | 10.7% · 0 · 46% | 14.3% · 0 · 44% |
| 중간 | 전설/대가 | 50.3% · 0 · 26% | 49.7% · 0 · 57% |

기술 덱에선 대가/상급의 시간 판정이 49 → 33으로 줄었지만 전설/대가는 101 → 108로 늘었다. 한쪽으로 기울지 않는다.

### 처음 만든 판단이 왜 대가를 약하게 했나

처음엔 대가가 새 마법을 가지면 오히려 졌다(중간 대가/상급, 새 마법 없는 대가 45% → 있는 대가 14%, 300판). 하나씩 고쳤다:

| 고친 것 | 까닭 | 중간 대가/상급 (200~300판) |
|---|---|---|
| (처음) | | 14% |
| 붙잡기 마법을 피해로 치지 않음 | 간격이 빌 때마다 약한 붙잡기(피해 4~5)를 쏘아 머리만 뜨거워졌다 | 22% |
| 균사·석회 탄을 빠르고 넓게(16 → 28·26 m/s), 경직 실을 빠르게 | 16 m/s 탄은 상급이 걸어서 피했다(균사 161번 중 5번, 석회 113번 중 3번 맞음) | — |
| 기둥을 대각선 → 앞뒤·양옆 → ±60°·±120°, 과녁이 갈 자리에 | 대각선 기둥은 옆으로 구르는 길이 틈이었고, 앞 기둥은 제 실을 막았다(대가의 실 피해가 절반). 시전 동안 4 m 움직인 과녁을 못 가뒀다 | 35 → 43% |
| **기회 캔슬 버그 수정** | 묶인 틈을 보고 시작한 수에 표시(`down`)를 달지 않아, 다음 판단에 기회 캔슬이 그 수를 끊었다(1.8.0부터). 큰 수를 모으다 0.1 s 만에 끊고 다른 큰 수로 바꾸기를 되풀이했다 | — |
| **붙잡혀도 칠 수 있으면 모으지 않음** | 몸 묶기는 굳힘과 달리 시전을 막지 못한다. 붙잡은 과녁이 짧은 실로 쳐서 역류시켰다(평범 역류 0.3 → 0.12번/판) | 42% |
| 붙잡기도 그 조건으로 | 걸어 두고 큰 수를 못 이으면 붙잡기에 쓴 시간만 버린다 | **50.5%** (새 마법 없는 대가 48.5%) |

- **배운 것: 몸 묶기는 "못 피한다"만 주고 "못 끊는다"는 주지 않는다.** 위험 규칙의 큰 수는 끊기면 역류하므로, 몸 묶기만으로 여는 틈은 과녁의 공격이 모두 간격 중일 때로 좁다. 그래서 큰 수가 한 판에 1번도 안 되고, 시간 판정이 줄지 않는다
- 다음 후보(이번엔 하지 않음): ① 몸 묶기를 큰 수가 아니라 보통 지연 폭발(불기둥·땅 번개)의 콤보에도 쓰게 한다. 큰 수보다 흔해 판 길이에 닿을 수 있다 ② 경직이 시전도 늦추게(예비동작 × 1.3) 하면 "못 끊는다"의 일부를 준다 — 규칙의 뜻이 바뀌므로 SPEC부터

### 기회 캔슬 버그 수정의 영향

`down` 표시만 고치고 표준 묶음을 돌리면 13줄이 움직였고 모두 운 범위였다(가장 큰 것: 평범 전설/대가 63 → 57%, z = −0.8. 평범 대가/상급 risk 75 → 81%, z = 1.0).

```
node cli.js suite 몸 묶기
node cli.js duel 평범 평범 100   # 규칙은 장면 JSON의 rules나 A.duel(..., { rules: { risk: true, bodyBind: true } })로
```
