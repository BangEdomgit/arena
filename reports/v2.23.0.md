# 45-2. 몸 털기 거둠·위험 지대 단계·판이 끝을 강요함 (v2.23.0)

정한 것 넷:
1. 몸 털기는 굳음을 못 턴다. 굳힘 내성만 남긴다.
2. `hazard`의 길·소금 원 여유는 상급부터, 붙잡은 수를 풀 때 내 거리 보기는 대가부터.
3. 판을 끝낸 까닭에 '판이 끝을 강요함'(소금 원)을 따로 둔다.
4. 감각 조준 × 드러남 대신 숨긴 수만 × 0.6.

규칙은 SPEC 45장 끝, 문턱은 [`gate.md`](gate.md) (✓ 41 · ✗ 29 · △ 17 · — 2).

## 고치기 전에 잰 것 (v2.22의 판, 결투장 전설 대 전설 200판)

| 잰 것 | 값 |
|---|---|
| 메이트의 결정타가 시작될 때 과녁 체력 | 중앙 3%, 10% 아래 91% (56판 가운데 51) |
| 받은 적 피해 가운데: 응수가 있던 수 / 응수가 없던 수 / 알아채지 못한 수 / 못 짚음 | 35% / 31% / 30% / 3% |
| 메이트 가운데 큰 수를 쓸 수 있었는데 작은 수로 끝낸 몫 | 80% (56 가운데 45). 큰 수로 끝낸 것 11 |

- 메이트는 거의 다 체력 10% 아래에서 끝내는 한 방이다(수읽기의 끝내기 `finHp` 0.15).
- 피해의 3분의 1이 응수가 있던 수에서 온다. "응수가 있으면 덜 다친다"는 이 3분의 1에만 닿는다.
- 거의 모든 메이트에서 큰 수를 쓸 수 있었지만, 이미 체력이 바닥이라 작은 수로 충분했다.
- 이 셋은 문턱의 '봄' 줄(B16·B17·C13)로 남겼다.

**바로잡음**: v2.21에 넣은 "풀 때 응수를 다시 세기"가 실(풀자마자 닿는다)에선 무엇이든 0으로 셌다. 과녁이 굳어 있을 때만 다시 세게 고쳤다(메이트 45 → 44%, 200판).

## 감각 조준: 숨긴 수만 × 0.6 (200판, 1~3을 넣은 위에서)

| | × 1 (끔, 넣은 것) | × 0.6 |
|---|---|---|
| 공격 명중률 (30~45%) | 33.5% ✓ | **26.7% ✗** |
| 실수로 입은 피해 (10% 이하) | 6.0% ✓ | 7.6% ✓ |
| 정보의 열매 E8 | 14.2%p | **8.2%p** (내려간다) |
| 흐름 | 34% | 42% |
| 판 길이 | 61.1 s | 65.0 s |
| 메이트 | 54% | 50% |

숨긴 수는 대개 못 알아챈 수다. 그 수의 조준을 줄이면 못 알아챈 수의 명중이 떨어져 정보의 열매도 줄어든다. 명중률 문턱이 무너지므로 `trackHid` 1(끔)으로 두었다.

## 읽기

- 털기를 거두니 메이트와 큰 한 방이 돌아오고 판이 짧아졌다(64 → 61 s). 판 길이는 문턱 바로 위다.
- `hazard`를 상급에 주니 대가/상급이 내려왔다(0.91 → 0.82). 대신 상급/중급이 벌어졌다(0.83 → 0.89).
- 전설/대가는 그대로다(0.88~0.92). 털기 판단은 전설만의 것이 아니었다. 이 사다리를 벌리는 것은 그 밖의 전설 기술이다.
- 흐름은 그대로 34%. 판의 앞쪽에서 잃고, 메이트는 체력 5% 안팎의 마지막 한 방이다.
