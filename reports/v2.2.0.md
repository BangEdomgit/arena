## 26. v2.2.0

### 출발점: 요청에 적힌 기록과 재현

요청의 기록은 '대마법사 성' 덱으로 보인다(벽 2%, 근육 폭주·낙뢰·체인). 새 기술을 끈 이 판(200판)에서 잰 값:

| | 요청의 기록 | 재현 (전설끼리, 끔) |
|---|---|---|
| 판 길이 | 38 s | 35.7 s |
| 거리 | 늘 21 m | 11.7 m (±7.1) |
| 초당 시전 | 0.9 | 1.23 |
| 두 번째 칸 판당 | 14 | 0 |
| 입장 | 늘 보통 | 늘 보통 |
| 근육 폭주 | 18% | 8% (명중 0) |
| 낙뢰 | 7%, 명중 0% | 11%, 명중 8% |
| 체인 | 4%, 명중 4% | 8%, 명중 5% |

거리·두 번째 칸 수는 다르다(재는 법이나 덱이 다른 것으로 보인다. 여기선 처음 50 m 안으로 만난 뒤부터 0.5 s마다 쟀다).

### 한눈에 — 판단 단계가 갈리는가 (점수는 앞 사람, 200판, 표준오차 ±0.035)

| 대진 | 성 덱: 끔 → 켬 | 운영 덱: 끔 → 켬 |
|---|---|---|
| 전설 / 대가 | 0.475 → **0.63** | 0.395 → **0.635** |
| 대가 / 상급 | 0.415 → **0.49** | 0.435 → **0.405** |
| 상급 / 중급 | 0.575 → 0.568 | 0.545 → 0.615 |
| 전설 / 전설 | 0.515 → 0.46 | 0.485 → 0.465 |

- **전설이 대가를 이긴다**: 끄면 전설이 오히려 약간 졌다(0.40~0.48). 켜면 0.63
- **대가는 상급을 넘지 못한다** ✗: 끈 판에서도 0.42~0.44다. 대마법사 급에서는 원래 대가가 상급에게 약간 진다
  - 대가의 기술을 떼 보니(100판) 짙은 땅(끄면 +0.06), 기회 캔슬(+0.08), 효과 학습(+0.04)이 해로웠다
  - 짙은 땅과 기회 캔슬은 들어가기·빠지기 중에 끼어들지 않게 고쳤다(짙은 땅은 요청대로 켜 둔 채)
  - 그래도 0.49 / 0.405다

### 모습 지표 (전설 / 대가, 끔 → 켬)

| 지표 | 성 덱 | 운영 덱 |
|---|---|---|
| 판 길이 | 30.2 → 39.6 s | 32.7 → 39.0 s |
| 평균 거리 | 12.1 → 20.2 m | 11.5 → 20.9 m |
| 거리 표준편차 (리듬) | 7.2 → 8.2 m | 7.1 → 8.1 m |
| 거리 흔들림 (표준편차 / 평균) | 0.60 → 0.41 | 0.63 → 0.39 |
| 리듬 단계 (떠보기 · 들어가기 · 빠지기) | — → 41% · 11% · 49% | — → 42% · 9% · 49% |
| 초당 시전 | 1.24 → 0.86 | 1.20 → 0.90 |
| 두 번째 칸 판당 | 0 → 4.0 | 0.1 → 3.8 |
| 두 번째 칸 역할 | — → 공격 90% · 방어 10% | — → 공격 69% · 지형 17% · 방어 14% |
| 근육 폭주 몫 | 7.8% → 0% | 7.4% → 0% |
| 헛손질 (공격의 못 맞힌 몫) | 0.78 → **0.82** | 0.80 → **0.86** |
| 장악 경계 틈 (경계에서 상대까지) | 6.0 → 10.1 m | 5.7 → 10.4 m |
| 장악 경계 이동 | 6.8 → 9.2 m/s | 7.1 → 10.0 m/s |
| 세운 지형 / 없앤 지형 (판당) | 0 / 0 | 3.3 → 6.1 / 0 → 0 |

지표별로 읽으면:
- **리듬은 보인다**: 멀리서 떠보고, 틈에 들어가고, 넘치기 직전엔 빠진다
  - 전설끼리(성)는 떠보기 47% · 들어가기 27% · 빠지기 26%다
  - 거리의 절대 흔들림이 늘었다(±7 → ±8 m). 평균 거리가 두 배 가까이 되어 비율(흔들림)은 줄었다
- **두 번째 칸이 일한다**: 판당 0 → 4. 운영 덱에서는 지형 17%다
- **강화 버프 낭비가 사라졌다**: 날면서 쓰던 근육 폭주(명중·효과 0)가 0%다
- **헛손질은 늘었다** ✗
  - 효과 학습은 한 번도 못 맞힌 수를 버리지만(다섯 번 뒤), 싸움이 12 m에서 20 m로 멀어졌다. 먼 거리에서 닿는 수(낙뢰·돌 비)는 나는 과녁에 3~8%만 맞는다
  - 한 번도 못 맞힌 수를 버리는 것을 더하기 전에는 0.85·0.87이었다
- **장악권 경계**: 들어가기에서 장악권 밀기가 붙을 거리(같은 신호면 6 m)를 정한다. 떠보기·빠지기가 길어 평균 틈은 오히려 늘었다(6 → 10 m). 경계는 더 많이 움직인다(리듬)
- **지형 설계**
  - 운영 덱에서는 세운 지형이 판당 3.3 → 6.1로 늘었다(석회 기둥: 빠질 때의 엄폐, 몰이 자리)
  - **없앤 지형은 0**이다: 벽 밀기로 깔 적이 벽 너머에 선 판이 없었고, 산으로 녹인 벽도 없었다
  - 성 덱에는 빨리 서는 벽이 없다(흙벽 3.4 s)
