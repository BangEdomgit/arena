## 28. v2.4.0

### 한눈에 — 단계가 갈리는가 (점수는 앞 사람)

| 대진 | v2.3 | + 반사 겹 | + 끊는 움직임 | + 청사진 | 셋 다 |
|---|---|---|---|---|---|
| 전설 / 대가 | 0.935 | 0.905 | 0.885 | 0.935 | **0.935** |
| 전설 / 전설 | 0.537 | 0.575 | 0.497 | 0.53 | 0.532 |
| 대가 / 상급 | 0.61 | 0.63 | 0.537 | 0.62 | **0.605** |

땅 싸움(비행 끔)에서 끊는 움직임 + 반사 겹을 켜면:
- 전설 / 대가 0.978 → 0.82
- 대가 / 상급 0.578 → 0.61

셋 다 켜도 사다리는 그대로다. 하나씩 보면 셋 모두 점수를 거의 바꾸지 않는다(±0.03).

### 기술 떼기 (셋 다 켬, 앞 사람만, 200판)

| 뗀 것 | 전설 / 대가 | 대가 / 상급 |
|---|---|---|
| 없음 | 0.935 | 0.605 |
| 반사 겹 (`reflex` 0) | 0.93 | 0.58 |
| 발놀림·끊어 걷기 (`footwork` 0, `chop` 끔) | **0.85** | **0.515** |
| 청사진 (`blueprint` 0) | 0.915 | **0.723** |
| 상황 고르기 없이 첫 청사진 (`blueprint` 1) | 0.98 | 0.61 |

- **발놀림은 먹힌다**: 떼면 전설은 −0.085, 대가는 −0.09
- **반사 겹은 거의 차이가 없다**(±0.03): 대가·전설의 생각 겹이 이미 0.05~0.08 s마다 돈다(아래 반응 시간)
- **대가의 청사진은 상급 앞에서 해롭다** ✗: 안 지으면 0.605 → 0.723
  - 전설은 거의 같다(0.915 대 0.935)
  - 전설은 상황에 맞게 고르기보다 반원 보루만 짓는 게 약간 낫다(0.98)

### 모습 지표 (셋 다 켬; v2.3 · 생각 겹만 → 켬)

**움직임** (앞 / 뒤 사람)

| | 전설 / 대가 | 전설 / 전설 | 대가 / 상급 | 땅: 전설 / 대가 |
|---|---|---|---|---|
| 초당 방향 전환 (0.1 s에 90° 넘게) | 0.19 / 0.87 → **0.37** / 0.86 | 0.18 / 0.17 → **0.48 / 0.49** | 1.07 / 0.55 → 0.78 / 0.41 | 1.16 / 1.07 → **1.45** / 0.82 |
| 반응 시간 (ms) | 100 / 114 → 104 / 123 | 103 / 101 → 92 / 89 | 121 / 157 → 115 / 161 | — → 89 / 110 |
| 반응 못 한 몫 | 0.34 / 0.40 → 0.36 / 0.36 | 0.31 / 0.28 → **0.23 / 0.25** | 0.36 / 0.62 → **0.25** / 0.60 | — → 0.14 / 0.15 |
| 흔들기 (판당) | — → 0.7 / 0.9 | — → 1.0 / 1.0 | — → 0.6 / 0 | — → 1.0 / 1.1 |
| 피하기 (반사 겹, 판당) | — → 5.8 | — → 8.8 | — → 5.1 | — → 13.3 |

| 내려앉기-구르기-떠오르기 (판당) | 0.1 | 0.1 | 0.01 | — |

- **끊김이 보인다**
  - 날 때 전설의 방향 전환이 두 배(0.19 → 0.37~0.48/s)
  - 땅에서는 1.16 → 1.45/s
  - 날 때의 방향 전환이 땅보다 적은 까닭: 대마법사는 판의 절반 가까이를 빠지기(50 m/s)로 보낸다. 그 속도에선 옆 5 g로도 0.1 s 안에 방향을 90° 넘게 돌리지 못한다(게걸음 비행은 붙어 싸울 때만)
  - 대가는 v2.3에서도 이미 0.87~1.07/s였다. 늘지 않았다
- **반사 겹의 몫은 작다** ✗
  - 반응 시간은 생각 겹만일 때와 거의 같다(90~120 ms)
  - 반응 못 한 몫은 전설끼리·대가(대 상급)에서 0.31~0.36 → 0.23~0.25로 줄었다. 전설 / 대가에서는 그대로다
  - 까닭: 대가·전설의 생각 겹은 0.08·0.05 s마다 돌고, 읽기(`readThreats`)가 이미 0.8 s 앞의 투사체와 예비동작을 본다. 반사 겹의 지연(0.1·0.05 s)과 거의 같다
  - 판단 간격이 긴 사람(중급 0.2 s, 초보 0.3 s)에게 반사 겹을 주면 차이가 클 것이다(재지 않음)
- **흔들기는 먹히지 않는다** ✗: 흔든 뒤 나를 겨눈 공격이 오히려 더 맞았다(빗나감 0.84~0.89 대 0.93~0.97). 판당 1번 안팎이라 판을 바꾸지는 않는다
  - 처음(모든 예비동작, 구름·곡사 포함)에는 판당 20번 흔들었다. 전설/대가 0.935 → 0.65, 대가/상급 0.61 → 0.48로 무너졌다
  - 흔들기의 덮는 걸음이 생각 겹의 피하기를 덮었고, 거의 나를 겨눈 수에 흔들면 맞는 반지름 안에 남았다
  - 투사체·실만, 앞길을 2 m 넘게 앞에 겨눴을 때만 흔들고, 진짜 위협이 오면 거두게 고쳤다
