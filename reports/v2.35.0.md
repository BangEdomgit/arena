# v2.35.0 합창의 체크와 메이트 (59절)

SPEC 57장. 막는 수는 `experiments/bound.js`로, 수마다 16판씩 쟀다. 무리는 상위 전투단(대가·상급, 덱 셋, 합창 + 합창 설계)이다. 갇힌 판(c32)은 24판이다. 문턱은 `node cli.js gate`(H14~H17은 8판)이다. 결과 지문 넷은 그대로이고 suite는 바뀐 줄이 없다. 시험은 112개 → 113개다.

## 59-1. 무엇을 바꿨나

- 합창의 수를 둘로 나눴다.
  - 체크: 번개 장막·석회 고리·고요한 원.
  - 메이트: 대낙뢰·걸어둔 구름·화산 기둥.
- 메이트는 수읽기의 줄인 상태로 판단한다(39장의 `plan/state`, 규칙은 `B.lib.plan`으로 쓴다). 터지기까지(예비동작 + 지연) 과녁이 반지름 밖으로 빠져나갈 수 없을 때만 짓는다.
- 맞을 가망: 빠져나가면 0.1, 못 하면 1이다. 막기가 있으면 × 0.5다.
- 겨냥은 그때 과녁이 있을 자리다.
- 날 수 없는 과녁은 피할 곳까지의 길이 담·벽에 막히는지도 본다. 피할 곳은 끝점만 보던 것을 고쳤다.
- 큰 수의 몫(16판 합, 전투단 50 대 전설):

| | v2.34 | v2.35 |
|---|---|---|
| 걸어둔 구름 | 447 | 0 |
| 대낙뢰 | 8 | 4 |
| 번개 장막 | 86 | 241 |
| 석회 고리 | 135 | 180 |

- 메이트는 판마다 0.3~0.9번이다. 그 거의 모두가 체크 뒤 6 s 안이다.
- 메이트의 명중:

| N | 대낙뢰 | 화산 기둥 |
|---|---|---|
| 40 | 5/5 | |
| 50 | 2/4 | |
| 60 | 7/10 | 0/2 |
| 70 | 3/5 | |

  - 대가 판 30에서는 대낙뢰 8/8, 화산 기둥 2/3이었다.

| 서클 8 대가 | 94% | 38% | 19% | 6% | | | | **약 27** | 약 45 | 20~40 ✓ |
| 서클 11 대가 | | 50% | 19% | | | | | **약 30** | 약 45 | 20~40 ✓ |

**합창이 세졌다.** 앞소리꾼이 피하기 쉬운 걸어둔 구름을 버렸다. 그 시간에 빠른 번개 그물과 체크를 쓴다.
- 전설이 입은 피해에서 앞소리꾼의 몫이 37% → 49%, 번개 그물의 몫이 7% → 20%로 올랐다.
- 대가는 목표 안에 들었다. 전설은 v2.33 수준(약 45)으로 돌아갔다.

**전설만의 판단으로 해 본 것** (합창 깨기에 더함, 대가에게는 주지 않음):
1. 고요한 원 안이면 밖으로 나가고, 원을 쥔 앞소리꾼을 먼저 노린다.
   - 원 안에 있던 시간은 판마다 0.1~3.8 s였다. 경계를 옮기지 못했다.
2. 합창의 번개 앞에서 내려앉지 않는다.
   - 비행 판단(24장)은 "번개 위협엔 내려앉는다"였다. 전설이 합창의 번개 그물에 맞은 37번 가운데 36번이 땅에서였다.
   - 고친 뒤에도 땅에서 맞은 18번 가운데 17번은 이미 굳은 채였다. 합창원의 실·체인으로 굳힌 뒤 그물이 들어온다. 무리의 체크 → 메이트다.
   - 전투단 70에서 0% → 19%로 올렸다.

**전설의 경계가 목표에 못 미치는 까닭:**
- 둘러싸인 판에서 실·체인으로 굳는 사슬을 피할 판단이 없다. 굳음은 털 수 없다(45장).
- 합창의 위력 곱(× √N^2.5)은 그대로 두었다.
