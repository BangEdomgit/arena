# v2.28.0 마름·물러서기·막는 수와 잡는 수 (52절)

## 52-3. 마름 (`drain`, 기본 꺼짐)

곳간 크기마다 중간 전투단 대 서클 11 전설을 쟀다(4판). 칸마다 곳간이 있고, 다시 차는 데 약 3분이다.

| 곳간 (칸마다) | 중간 200 | 중간 300 | 중간 500 | 중간 800 |
|---|---|---|---|---|
| 마름 없음 | 승 50% · 물러남 50% | 25 · 75% | — | 0 · 100% |
| 300 (둘레 3 × 3 칸) | 승 0% · 물러남 100% | 0 · 100% (체력 25%) | — | 0 · 100% |
| 600 | — | 0 · 100% | 0 · 100% | 0 · 100% |
| 1500 (기본) | 50 · 50% | 25 · 75% | 0 · 100% | 0 · 100% |
| 4000 | — | 25 · 75% | 0 · 100% | 0 · 100% |

- 흩어진 중간(전투단 없이)은 마름이 있어도 300·800에서 대마법사가 100% 이긴다(체력 98~100%). 중간의 수가 대마법사에게 닿지 않는다.
- 마름은 중간의 경계를 거의 옮기지 않는다. 대마법사의 수는 중간을 40배 넘치게 쓰러뜨려, 위력이 몫만큼 줄어도 계속 쓰러뜨린다. 중간의 경계(약 200)를 만든 것은 합창 자리다.
- 처음 둔 것(곳간 2만, 둘레 1칸)은 곳간이 남아 효과가 없었다. 둘레를 3칸으로 넓히고 곳간을 줄였다.

**결투장 전설 대 전설 (tactics-legend, 30판)**

| | 판 길이 | 앞 사람 승 | 모자란 시전 |
|---|---|---|---|
| 마름 없음 | 62 s | 57% | — |
| 곳간 300 | 80 s | 50% | 91% |
| 곳간 1500 | 38 s | 43% | 13% |

- 곳간 1500에서 판이 짧아진다. 마른 땅에서는 떡대가 벗겨지기 때문이다. 곳간 300은 위력이 줄어 판이 길어진다.
