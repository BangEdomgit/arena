# v2.39.0 붙잡기 (63절)

SPEC 60장. 새 규칙 `ringHold`는 기본 꺼짐이고, 장부 `ringLedger` 위에서만 돈다. 이 장의 수는 모두 둘을 켜고 잰 것이다. 끄면 결과 지문 넷이 그대로이고, suite는 바뀐 줄이 없고, 속도도 그대로다. 시험은 122개 → 127개다(`test/t/v2i.js`).

- 결투장: 전설 대 전설, '대마법사 결투'
- 막는 수: `experiments/bound.js`(대가 16판, 전설 24판)
- 문턱: `node cli.js gate --rules '{"ringLedger":true,"ringHold":true}' --out reports/gate-ringHold.json`

## 63-1. 무엇을 넣었나

- **새긴 진**: 싸우기 전에 서클 − 일하는 고리만큼 새긴다(대마법사 최대 6: 서클 8은 넷, 서클 11은 여섯).
  - 서클 11 전설: 자동 대처·자동 절연 막·자동 굳은 살·자동 쿠션·자동 열 차단·자동 치유
  - 서클 8 전설: 앞의 넷
  - 반사라 고르지 않는다. 헛켜짐이 있고, 숨긴 수엔 움직이지 않는다.
- **잔기술 여럿 함께 켜 두기**: 상대가 쥔 준비된 수의 종류, 전설의 절연 막 켜 두기
- **준비된 수**: 조용할 때 셋째 칸 대신 지어 쥔다. 기회에 한꺼번에 푼다.
  - 짓는 머리 열은 다 지을 때 낸다. 붙잡기는 하나에 초당 0.3이다.
  - 상대는 빛나는 고리를 세어 숨을 미루고, 그 종류의 잔기술을 켜 둔다.

## 63-6. 문턱 (장부 + 붙잡기 켬)

문턱 전체: ✓ 44 · ✗ 38 · △ 17 (장부만 v2.38: ✓ 44 · ✗ 37 · △ 18). 값이 움직인 줄:

| 줄 | 장부만 (v2.38) | 장부 + 붙잡기 |
|---|---|---|
| B 판 길이 | △ 60.6 s | **✗ 67.3 s** (목표를 넘었다) |
| B 0.5 s 넘게 서 있는 순간 | ✗ 1.19 | ✗ 1.64 |
| B 1 s에 잃은 최대 체력 | ✓ 19% | ✓ 14% |
| B 흐름: 마지막 3분의 1에 잃은 몫 | ✗ 32% | ✗ 39% |
| C 큰 한 방 | ✗ 0.55 | ✗ 0.71 |
| C 속임수 | ✓ 15.4 | ✓ 18.0 |
| C 메이트로 끝난 판 | △ 50% | △ 46% |
| E 패시브가 막은 피해 몫 | ✓ 22% | ✓ 24% |
| E 숨 마시다 맞음 | ✗ 0.43 | ✗ 0.54 |
| E 정보의 열매 | ✗ 12% | ✗ 10% |
| H17 갇힌 판 (8판) | △ 88% | △ 50% |
| 대마법사 결투 한 판 계산 | 0.36 s | 0.44 s |

- B에서 판정이 나빠진 줄이 하나다: 판 길이 △ → ✗. 진과 함께 켠 잔기술이 막는 몫이 늘어 판이 길어졌다(1 s에 잃는 최대 체력 19 → 14%).
- 0.5 s 넘게 서 있는 순간이 늘었다(1.19 → 1.64). 준비된 수를 지을 때 서는 것으로 본다. 아직 떼어 재지 않았다.
- 숨 마시다 맞음은 0.43 → 0.54로 다시 나빠졌다.
- 계산이 한 판 0.36 → 0.44 s로 느려졌다(자동 잔기술이 걸음마다 상대의 수를 본다). 문턱 1 s 안이다.
